# Project Vision

## Goal

Build a realistic Industrial Production Monitoring System that simulates
factory machines, receives production data through an ASP.NET Core API,
stores it in SQL Server, and displays live information in an Angular
dashboard.

## Finished System

Components:

1.  Machine Simulator
2.  ASP.NET Core Web API
3.  SQL Server Database
4.  Angular Dashboard
5.  Administration Module

The system should demonstrate Clean Architecture, Domain-Driven Design
concepts, SignalR, authentication, logging, testing, Docker, and Azure
deployment.
