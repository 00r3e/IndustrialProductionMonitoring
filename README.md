# Industrial Production Monitoring System

## Overview

A portfolio-quality Industrial Production Monitoring System built with
ASP.NET Core, Angular, SQL Server, Entity Framework Core, SignalR, and
Clean Architecture.

This repository demonstrates professional backend architecture rather
than a simple CRUD application.

## Technology Stack

-   ASP.NET Core (.NET 8)
-   Entity Framework Core 8
-   SQL Server
-   Angular
-   SignalR
-   JWT Authentication (planned)
-   Docker (planned)
-   Azure (planned)

See the **docs/** folder for detailed project documentation.
